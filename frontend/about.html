About Our Project

The Oral Disease Detection System is an Artificial Intelligence based web application developed using Deep Learning and CNN algorithms. This project helps in detecting oral diseases from mouth images quickly and accurately.

Project Information

Deep Learning

Uses Convolutional Neural Networks (CNN) to analyze oral images and identify diseases.

Image Processing

Uploaded images are preprocessed and passed through the trained AI model.

Prediction Accuracy

The system predicts oral disease type and displays confidence percentage.

Technologies Used

This project is developed using HTML, CSS, Bootstrap, JavaScript, PHP, Python, TensorFlow, Keras and MySQL database.

The CNN model is trained using oral disease datasets containing multiple disease classes.
