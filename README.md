# Oral Cancer Detection System

## About the Project
The Oral Cancer Detection System is a web-based academic project developed to assist in oral cancer screening. It provides two methods of assessment: image-based detection and description-based detection.

## Features
- Image-based detection through uploaded oral cavity images.
- Description-based assessment using user-provided information.
- User-friendly web interface.
- Database integration for managing application data.

## Technologies Used
- Python
- PHP
- MySQL
- HTML
- CSS
- JavaScript 

## How It Works
1. Users access the web application.
2. They choose image-based detection or description-based assessment.
3. The system processes the submitted input.
4. The application displays the assessment result.

## Installation and Setup
1. Install XAMPP.
2. Copy the project folder into the `htdocs` directory.
3. Start Apache and MySQL.
4. Import the required MySQL database.
5. Configure the database connection.
6. Open the browser and visit:

   `http://localhost/oral_cancer_detector/`
